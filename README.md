# Lead Scraper Pro

A Flask-based web application that scrapes business leads from Yellow Pages.

## Features
- Search for businesses by keyword and city
- Multi-page scraping support
- Real-time progress tracking
- Export leads to CSV

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

The app runs on `http://127.0.0.1:5001`.
